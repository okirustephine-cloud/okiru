# Portfolio Starter Template

## Folder structure
portfolio/
├── index.html
├── stylesheet.css
├── main.js
└── images/          <-- put your photos / project screenshots here

## What to customize
1. **index.html** — search for `TODO` and replace every `[placeholder]` with your info.
2. **main.js** — update the Typed.js `strings` array and the `projectsData` array.
3. **stylesheet.css** — optional: change `--accent` and fonts in `:root` to make it yours.
4. **images/** — add your hero image (`portfolio.png`), about photo, and project previews.

## Tips
- Keep image file names short and lowercase (no spaces).
- Test in the browser after each section.
- The contact form opens the user's email client (mailto). For real email sending, you'd need a backend or a service like Formspree.
